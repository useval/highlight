### `CodeView`

Shows syntax-highlighted code.

```dart
CodeView(source, language: dartLanguage)
```

Everything else is optional. The theme follows the app's brightness
(see `CodeTheme` for app-wide defaults). Results are cached, and inputs
above `CodeHighlighter.isolateThreshold` are highlighted in a background
isolate while plain text is shown.

Short code renders as one text block. Code with more than
`virtualizeAbove` lines, placed where its height is bounded, renders one
row per line in a lazy list, so only visible lines are laid out.

```dart
const CodeView(
  String code, {
  Key? key,
  Grammar? language,
  List<Grammar> detectLanguages = const [],
  Grammar fallbackLanguage = genericLanguage,
  ValTheme? theme,
  TextStyle? textStyle,
  EdgeInsetsGeometry? padding,
  bool? lineNumbers,
  int firstLineNumber = 1,
  Set<int> highlightedLines = const {},
  Color? highlightColor,
  bool wrap = false,
  bool selectable = true,
  CodeHighlighter? highlighter,
  int virtualizeAbove = 1000,
  CodeGutterBuilder? gutterBuilder,
  CodeLineBuilder? lineBuilder,
  Widget? header,
  ScrollController? scrollController,
  ValueChanged<CodeToken>? onTokenTap,
  CodeSpanBuilder? spanBuilder,
})
```

Creates a code view.

| Field | Type | Default | Description |
|---|---|---|---|
| `code` | `String` | *required* | Source code to show. |
| `language` | `Grammar?` |  | Language of `code`. When `null`, the language is detected among `detectLanguages`; if that fails, `fallbackLanguage` is used. |
| `fallbackLanguage` | `Grammar` | `genericLanguage` | Language used when `language` is `null` and detection finds nothing. Defaults to `genericLanguage`, which highlights what most languages share. Use `plainTextLanguage` for no highlighting. |
| `detectLanguages` | `List<Grammar>` | `const []` | Candidates for detection when `language` is `null`. |
| `theme` | `ValTheme?` |  | Color theme. Defaults to `CodeTheme` or the built-in light/dark theme. |
| `textStyle` | `TextStyle?` |  | Text style merged over the default monospace style. |
| `padding` | `EdgeInsetsGeometry?` |  | Padding inside the background. Defaults to `CodeTheme.padding`, or 16 on every side. |
| `lineNumbers` | `bool?` |  | Whether to show line numbers. Defaults to `CodeTheme.lineNumbers`, or `false`. |
| `firstLineNumber` | `int` | `1` | Number shown for the first line. |
| `highlightedLines` | `Set<int>` | `const {}` | Line numbers (as shown in the gutter) to highlight. |
| `highlightColor` | `Color?` |  | Background for `highlightedLines`. |
| `wrap` | `bool` | `false` | Whether long lines wrap. When `false`, code scrolls horizontally. |
| `selectable` | `bool` | `true` | Whether the code can be selected and copied. |
| `highlighter` | `CodeHighlighter?` |  | Highlighter to use. Defaults to `CodeHighlighter.shared`. |
| `virtualizeAbove` | `int` | `1000` | Line count above which rows are built lazily. |
| `gutterBuilder` | `CodeGutterBuilder?` |  | Custom gutter cells. |
| `lineBuilder` | `CodeLineBuilder?` |  | Custom rows. Setting this always renders one row per line. |
| `header` | `Widget?` |  | A widget shown above the code, such as a title or copy button. |
| `scrollController` | `ScrollController?` |  | Vertical scroll controller for the lazy list. |
| `onTokenTap` | `ValueChanged<CodeToken>?` |  | Called when a token is tapped, such as an identifier to jump to. Whitespace is not tappable. |
| `spanBuilder` | `CodeSpanBuilder?` |  | Builds each token's span, for hover effects, links, tooltips or custom styling. Takes priority over `onTokenTap`. |

### `CodeToken`

One piece of highlighted code, as passed to `CodeView.onTokenTap` and
`CodeView.spanBuilder`. Pieces never cross a line break.

```dart
const CodeToken({
  required String text,
  required int start,
  required int end,
  required int line,
  required List<String> scopes,
})
```

Creates a token.

| Field | Type | Default | Description |
|---|---|---|---|
| `text` | `String` | *required* | The token's source text. |
| `start` | `int` | *required* | Start offset in the code. |
| `end` | `int` | *required* | End offset (exclusive) in the code. |
| `line` | `int` | *required* | Zero-based line. |
| `scopes` | `List<String>` | *required* | Scopes from the outermost to the innermost; empty for plain text. |

| Member | Type | Description |
|---|---|---|
| `scope` | `String?` | Innermost scope, or `null` for plain text. |

### `CodeGutterBuilder`

Builds the gutter cell for `lineNumber`. Return a fixed-width widget so
rows stay aligned.

```dart
typedef CodeGutterBuilder = Widget Function(
  BuildContext context,
  int lineNumber,
  bool highlighted,
)
```

### `CodeLineBuilder`

Wraps the row for zero-based `line`. `child` is the default row.

```dart
typedef CodeLineBuilder = Widget Function(
  BuildContext context,
  int line,
  Widget child,
)
```

### `CodeSpanBuilder`

Builds the span for one `token`, replacing the default. `style` is the
token's themed style (`null` for plain text). Return a `TextSpan` with
`text: token.text` so the text stays unchanged.

```dart
typedef CodeSpanBuilder = InlineSpan Function(
  BuildContext context,
  CodeToken token,
  TextStyle? style,
)
```

### `CodeHighlighter`

Highlights code for widgets, with a result cache and background
isolates for large inputs.

Widgets use `CodeHighlighter.shared` unless given another. Create your
own to change the thresholds or to resolve Markdown code fences:

```dart
final highlighter = CodeHighlighter(registry: allLanguagesRegistry());
```

```dart
CodeHighlighter({
  LanguageRegistry? registry,
  int isolateThreshold = 50000,
  int cacheSize = 32,
})
```

Creates a highlighter.

| Field | Type | Default | Description |
|---|---|---|---|
| `registry` | `LanguageRegistry?` |  | Resolves languages named inside code, such as Markdown fences. |
| `isolateThreshold` | `int` | `50000` | Inputs with at least this many characters are highlighted in a background isolate by `highlight`. On the web, which has no isolates, they are highlighted on the next event-loop turn instead. |
| `cacheSize` | `int` | `32` | Number of results kept in the cache. |

| Member | Type | Description |
|---|---|---|
| `static shared` | `CodeHighlighter` | The default highlighter used by widgets. |
| `cached(String code, Grammar language)` | `HighlightResult?` | Cached result for `code` in `language`, if any. |
| `usesIsolate(String code)` | `bool` | Whether `highlight` would use a background isolate for `code`. |
| `highlightSync(String code, Grammar language)` | `HighlightResult` | Highlights `code` on the current isolate. |
| `highlight(String code, Grammar language)` | `Future<HighlightResult>` | Highlights `code`, using a background isolate for large inputs. |
| `preload(Iterable<Grammar> languages)` | `Future<void>` | Compiles `languages` ahead of time, one per idle frame, so the first code shown in each language has no compile delay (about 1–3 ms per language otherwise). |
| `clearCache()` | `void` | Empties the cache. |
