### `HtmlRenderer`

Renders a `HighlightResult` as HTML.

By default each scope becomes a `<span>` with CSS classes (pair it with
`ValTheme.toCss`). Pass `theme` to write inline `style` attributes instead,
which needs no stylesheet.

```dart
const HtmlRenderer({
  String classPrefix = 'vh-',
  String rootClass = 'vh',
  ValTheme? theme,
  bool wrap = false,
})
```

Creates an HTML renderer.

| Field | Type | Default | Description |
|---|---|---|---|
| `classPrefix` | `String` | `'vh-'` | Prefix for scope classes. Scope `title.function` becomes classes `vh-title vh-title-function`, so a theme can style either level. |
| `rootClass` | `String` | `'vh'` | Class of the `<pre>` element written when `wrap` is set. |
| `theme` | `ValTheme?` |  | When set, styles are written inline and no classes are used. |
| `wrap` | `bool` | `false` | Whether to wrap the output in `<pre><code>…</code></pre>`. The `<pre>` gets class `rootClass`, or, when `theme` is set, the theme's root style inline. |

| Member | Type | Description |
|---|---|---|
| `render(HighlightResult result)` | `String` | Renders `result`. |
