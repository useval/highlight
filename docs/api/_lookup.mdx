### `LanguageRegistry`

Languages addressable by name, alias, file name or file extension.

```dart
LanguageRegistry([
  Iterable<Grammar> languages = const [],
  Grammar? fallback,
])
```

Creates a registry containing `languages`.

`fallback` is used by `resolve` and `resolveFileName` when nothing
matches, and for embedded code (such as Markdown fences) in a language
the registry does not have.

| Field | Type | Description |
|---|---|---|
| `fallback` | `Grammar?` | Language used when nothing matches, or `null`. |

| Member | Type | Description |
|---|---|---|
| `languages` | `List<Grammar>` | Registered languages, in registration order. |
| `add(Grammar language, {List<String> aliases = const []})` | `void` | Registers `language` under its name, its aliases and any extra `aliases`. Later registrations replace earlier ones for the same key. |
| `lookup(String nameOrAlias)` | `Grammar?` | Language registered as `nameOrAlias`, or `null`. |
| `resolve(String nameOrAlias)` | `Grammar?` | Language registered as `nameOrAlias`, else `fallback`. |
| `resolveFileName(String fileName)` | `Grammar?` | Language for `fileName`, matched as `forFileName` does, else `fallback`. |
| `forFileName(String fileName)` | `Grammar?` | Language for `fileName` (a path is fine), matched by whole name, such as `Dockerfile`, then by extension, such as `main.dart`; or `null`. |

### `LanguageDetector`

Guesses the language of a piece of code.

Checks run from cheapest and surest to most expensive:

1. the file name, when given: a whole name such as `Dockerfile`, then
   the extension;
2. a `#!` first line against `Grammar.shebangs`;
3. a content score over the first `sampleSize` characters: each
   `Grammar.signatures` pattern that matches adds `signatureWeight`, and
   each keyword, literal or built-in type found by highlighting the
   sample adds `keywordWeight`. Invalid tokens subtract
   `invalidPenalty`.

This is a heuristic. When you know the language, pass it instead.

```dart
const LanguageDetector({
  int sampleSize = 4096,
  double signatureWeight = 10,
  double keywordWeight = 1,
  double invalidPenalty = 5,
  double minimumScore = 3,
})
```

Creates a detector.

| Field | Type | Default | Description |
|---|---|---|---|
| `sampleSize` | `int` | `4096` | Characters of input examined for the content score. |
| `signatureWeight` | `double` | `10` | Score added per matching signature pattern. |
| `keywordWeight` | `double` | `1` | Score added per keyword-like token. |
| `invalidPenalty` | `double` | `5` | Score subtracted per invalid token. |
| `minimumScore` | `double` | `3` | Content scores below this are treated as "unknown". |

| Member | Type | Description |
|---|---|---|
| `detect(…)` | `Detection?` | Detects the language of `code` among `candidates`, or returns `null` when nothing scores at least `minimumScore`. |

### `Detection`

A detected language and how confident the detector is.

```dart
const Detection(
  Grammar language,
  double score, {
  String reason = 'content',
})
```

Creates a detection result.

| Field | Type | Default | Description |
|---|---|---|---|
| `language` | `Grammar` | *required* | The detected language. |
| `score` | `double` | *required* | Detection score. Higher is more confident; only useful for comparing candidates for the same input. |
| `reason` | `String` | `'content'` | Why this language won: `file name`, `shebang` or `content`. |

### `allLanguagesRegistry`

A registry of every built-in language, for lookup by name, alias or file
name, and for Markdown code fences. Unknown names fall back to
`genericLanguage`.

```dart
LanguageRegistry allLanguagesRegistry()
```
