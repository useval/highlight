### `HighlightTextController`

A `TextEditingController` that highlights its text as you type.

```dart
final controller = HighlightTextController(language: dartLanguage);
TextField(controller: controller, maxLines: null, style: monospace);
```

Edits are highlighted incrementally: only the lines an edit can affect
are re-scanned, so typing stays fast in large documents. A plain
`TextField` still lays out and colors its whole text on every change;
for long text use `CodeField`, which colors only the lines on screen.

```dart
HighlightTextController({
  String? text,
  required Grammar language,
  ValTheme? theme,
  LanguageRegistry? registry,
})
```

Creates a controller for `language`.

`theme` defaults to `CodeTheme`'s theme for the current brightness.
`registry` resolves languages named inside the text, such as Markdown
code fences.

| Member | Type | Description |
|---|---|---|
| `language` | `Grammar` | The language of the text. Setting it re-highlights everything. *Settable.* |
| `theme` | `ValTheme?` | The theme, or `null` to follow `CodeTheme`. *Settable.* |
| `result` | `HighlightResult` | The highlight result for the current text. |

### `CodeEditingFormatter`

Applies `CodeEditing` to text typed into a field driven by a
`HighlightTextController`.

`CodeField` installs one automatically. Add one to a plain `TextField`'s
`inputFormatters` to get the same behavior there:

```dart
TextField(
  controller: controller,
  maxLines: null,
  inputFormatters: [CodeEditingFormatter(controller: controller)],
)
```

It reacts to text changes rather than key presses, so it works the same
with hardware keyboards, on-screen keyboards and voice input. Text being
composed by an input method is never changed. Each change it makes is a
single edit, so one undo reverts it.

What it needs to remember between edits, such as which closers it
inserted, is kept on the `controller`, so creating a new formatter in
each build is fine.

```dart
CodeEditingFormatter({
  required HighlightTextController controller,
  CodeEditing editing = const CodeEditing(),
  String indent = '  ',
})
```

Creates a formatter for `controller`.

| Field | Type | Default | Description |
|---|---|---|---|
| `controller` | `HighlightTextController` | *required* | The controller whose highlighting tells strings and comments apart. |
| `editing` | `CodeEditing` | `const CodeEditing()` | The behavior to apply. |
| `indent` | `String` | `'  '` | One level of indentation, for Enter. |
