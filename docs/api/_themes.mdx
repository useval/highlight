### `ValTheme`

A color theme: a `root` style plus a style per scope.

Scope lookup cascades: `title.function.call` tries `title.function.call`,
then `title.function`, then `title`.

```dart
const ValTheme({
  required String name,
  Style root = const Style(),
  Map<String, Style> styles = const {},
  bool dark = false,
})
```

Creates a theme.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | `String` | *required* | Theme name. |
| `root` | `Style` | `const Style()` | Base style for all code, including the background color. |
| `styles` | `Map<String, Style>` | `const {}` | Style per scope. |
| `dark` | `bool` | `false` | Whether this is a dark theme. |

| Member | Type | Description |
|---|---|---|
| `ValTheme.fromVsCode(Map<String, Object?> json, {String? name})` | `ValTheme` | Builds a theme from a decoded VS Code color theme (the JSON object of a `*-color-theme.json` file). |
| `ValTheme.fromVsCodeJson(String source, {String? name})` | `ValTheme` | Like `ValTheme.fromVsCode`, from the text of a theme file. Comments and trailing commas (JSONC) are allowed. |
| `lookup(String scope)` | `Style?` | Style for `scope` alone, using the cascade, without inheritance. |
| `resolve(ScopeTable table)` | `List<Style>` | Effective style of every stack in `table`, indexed by stack id. |
| `copyWith({…})` | `ValTheme` | Returns a copy with the given fields replaced. |
| `extend({String? name, Style? root, Map<String, Style>? styles})` | `ValTheme` | Returns a theme built on this one. |
| `toCss({String classPrefix = 'vh-', String rootClass = 'vh'})` | `String` | CSS for this theme, matching the classes written by `HtmlRenderer`. |

<details>
<summary><code>ValTheme.fromVsCode</code>: more</summary>

Uses the editor foreground and background, the theme `type` for
`dark`, and `tokenColors`, matching TextMate scopes the way VS Code
does. `name` defaults to the theme's own `name`.

</details>

<details>
<summary><code>resolve</code>: more</summary>

Each stack inherits from its parent, starting from `root`.

</details>

<details>
<summary><code>extend</code>: more</summary>

`root` is merged over the current root. Each entry in `styles` replaces
the style for that scope.

</details>

<summary><code>toCss</code>: more</summary>

`rootClass` is the class of the wrapping element. Scope `a.b` maps to
class `<classPrefix>a-b`.

</details>

### `Style`

Visual style for one scope. Unset fields inherit from the enclosing scope.

Colors are ARGB integers such as `0xFF1E7A3A`, so styles are `const` and
cost nothing to convert on any platform.

```dart
const Style({
  int? color,
  int? background,
  bool? bold,
  bool? italic,
  bool? underline,
  bool? strikethrough,
})
```

Creates a style.

| Field | Type | Description |
|---|---|---|
| `color` | `int?` | Foreground color as ARGB. |
| `background` | `int?` | Background color as ARGB. |
| `bold` | `bool?` | Bold text. |
| `italic` | `bool?` | Italic text. |
| `underline` | `bool?` | Underlined text. |
| `strikethrough` | `bool?` | Struck-through text. |

| Member | Type | Description |
|---|---|---|
| `isEmpty` | `bool` | Whether every field is unset. |
| `merge(Style? other)` | `Style` | Returns this style with the set fields of `other` applied on top. |
| `copyWith({…})` | `Style` | Returns a copy with the given fields replaced. |
| `toCss()` | `String` | CSS declarations for this style, such as `color:#1e7a3a;`. |

### `CodeTheme`

App-wide defaults for code widgets, set once on `ThemeData.extensions`.

```dart
MaterialApp(
  theme: ThemeData(extensions: [CodeTheme(light: myTheme)]),
)
```

Anything set directly on a widget wins over these defaults.

```dart
const CodeTheme({
  ValTheme? light,
  ValTheme? dark,
  TextStyle? textStyle,
  EdgeInsetsGeometry? padding,
  bool? lineNumbers,
})
```

Creates code defaults.

| Field | Type | Description |
|---|---|---|
| `light` | `ValTheme?` | Theme used when the app is light. Defaults to `lightTheme`. |
| `dark` | `ValTheme?` | Theme used when the app is dark. Defaults to `darkTheme`. |
| `textStyle` | `TextStyle?` | Base text style for code, merged over the default monospace style. |
| `padding` | `EdgeInsetsGeometry?` | Padding around code blocks. |
| `lineNumbers` | `bool?` | Whether code blocks show line numbers. |

| Member | Type | Description |
|---|---|---|
| `static maybeOf(BuildContext context)` | `CodeTheme?` | The nearest `CodeTheme`, if any. |
| `static resolve(BuildContext context, [ValTheme? override])` | `ValTheme` | The `ValTheme` to use: `override` if given, otherwise the app default for the current brightness. |
| `static textStyleOf(BuildContext context, [TextStyle? override])` | `TextStyle` | The default code text style: monospace, merged with `CodeTheme` and then `override`. |

<details>
<summary><code>static textStyleOf</code>: more</summary>

Letter and word spacing are fixed at zero so an app-wide text theme
cannot stretch code or its line numbers.

</details>
