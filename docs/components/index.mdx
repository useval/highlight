Every preview is rendered by the package's screenshot generator from the
example file shown on the page
([`tool/screenshots/examples/`](https://github.com/useval/highlight/tree/main/val_highlight_flutter/tool/screenshots/examples)),
in a light Material 3 app, so the picture and the code always agree. The
generator draws `monospace` with JetBrains Mono, and turns off its
ligatures so `=>` shows as typed.

The widgets take their app-wide defaults — the light and dark themes, the
code text style, and for `CodeView` its padding and line numbers — from a
`CodeTheme` set once on your `ThemeData`. See
[Themes](/docs/themes/#app-wide-defaults).
